## Exploración de código — usar codegraph primero
Antes de explorar, escribir o modificar código, usa siempre las herramientas MCP de codegraph:
- `codegraph_context` para entender un área o feature
- `codegraph_search` para localizar un símbolo por nombre
- `codegraph_trace` para trazar flujos entre dos puntos
- `codegraph_explore` para inspeccionar varios símbolos relacionados

Reserva `grep`/`find`/`Read` solo para confirmar detalles que codegraph no cubrió.
