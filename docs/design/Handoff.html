Tokens semánticos

Cambian de valor automáticamente cuando se aplica data-theme="dark" en <html>. Usá estos en componentes; nunca las escalas crudas para color de fondo/texto.

--color-bg stone-50 / stone-950 Fondo de la app
--color-surface #ffffff / stone-900 Cards, modales, list rows
--color-surface-2 stone-200 / stone-800 Surface secundaria
--color-ink #1a1a1a / #f1ede5 Texto primario
--color-ink-2 #4a4a48 / #b8b3a8 Texto secundario
--color-ink-3 #8a877f / #7a766d Eyebrow, meta, hint
--color-accent sage-600 / sage-400 Marca, CTAs, links
--color-accent-tint sage-100 / sage-900 Fondo del badge IA
--color-danger terra-500 / terra-400 Errores, eliminar
--color-line 10% ink Bordes de inputs, dividers fuertes
--color-line-2 6% ink Dividers sutiles

Componentes

Button

5 variantes × 3 tamaños. size="md" = 44px (touch target mínimo WCAG).

import { Button } from "@/components/ui"; <Button variant="accent" size="lg" icon={<Sparkles />}> Generar look </Button>

Input · Textarea

Underline-style. Soporta label, hint, error, prefix/suffix y el badge ✦ IA cuando el valor lo completó la IA.

Blusa de lino color crema
import { Input, Textarea } from "@/components/ui"; <Input label="Nombre" ai value={value} onChange={…} /> <Input label="Contraseña" type="password" error="Mínimo 8 caracteres" />

Badge · Chip

Badge es informativo y no interactivo; Chip es seleccionable.

Toast / Snackbar

Sistema con hook useToast(). Provider en layout.tsx; auto-dismiss a 3.5s.

✓ Prenda guardada
× No se pudo conectar
! Análisis incompleto
const { toast } = useToast(); toast.success("Prenda guardada"); toast.error("No se pudo conectar");

Pasos para integrar

  1. Copiar handoff/app/globals.css → app/globals.css e importarlo en layout.tsx.
  2. Copiar handoff/components/ui/ → components/ui/; copiar handoff/lib/cn.ts → lib/cn.ts.
  3. Instalar dependencias: pnpm add lucide-react next-themes.
  4. Cargar las fuentes con next/font en layout.tsx (Inter + Archivo Narrow + JetBrains Mono).
  5. Copiar handoff/public/ a public/ (manifest + icons).
  6. Envolver {children} con <ToastProvider> y <ThemeProvider attribute="data-theme">.
  7. Construir las pantallas sobre estos componentes — los frames del prototipo (LookSi.html) son la referencia visual.
